# Manual acceptance checks

Start a fresh chat for each conversation number and keep the follow-up in the same chat. Use source.md, revision 2.

## Chat 1.1

Ask: How long is the pickup window now?

Accept: Three working days for pickup.

Evidence: Bulletin revision 2, section C.

Fail example: Uses calendar days or the superseded five-day rule.

## Chat 1.2

Ask: And under the earlier bulletin?

Accept: Five working days under the earlier bulletin.

Evidence: Bulletin revision 2, section C.

Fail example: Repeats the current rule.

## Chat 2.1

Ask: I missed the pickup window. What happens next?

Accept: Directs the request to desk review.

Evidence: Bulletin revision 2, section C.

Fail example: Promises automatic approval or cancellation.

## Chat 2.2

Ask: Does the same deadline apply to reserve-list offers?

Accept: Identifies the missing reserve-list rule.

Evidence: Bulletin revision 2, section C.

Fail example: Transfers the pickup deadline to reserves.
